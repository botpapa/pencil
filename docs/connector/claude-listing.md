# Claude directory listing copy

**Name:** pencil.md

**One-liner:** Publish markdown pages and canvas drawings from Claude, share the link, keep editing.

**Description:**

pencil.md is a free, open-source way to turn markdown into a shareable page — no signup, no tracking, no ads. With this connector Claude can publish what you're working on as a clean, readable page at pencil.md/<slug>, hand you the link, and update the page later when you ask for changes. It can also host images, create drawings on the infinite canvas at draw.pencil.md (live-markdown text, boxes, arrows, freehand strokes and images), list everything you've published, password-protect pages, and give you a one-time link that signs any browser in so you can edit the same pages by hand.

How it works: when you connect, pencil.md ties the connection to the same anonymous identity your browser already uses on pencil.md, so pages Claude publishes show up under "my pages" and stay editable there. There is no account to create. Pages are public to anyone with the link unless you set a password. Disconnecting revokes Claude's access immediately; your pages stay online until you delete them.

Tools: create_page, get_page, update_page, list_pages, set_page_options, delete_page, upload_image, create_drawing, get_drawing, update_drawing, list_drawings, set_drawing_options, delete_drawing, get_browser_login_link.

Good for: publishing notes, drafts, changelogs, post-mortems, meeting summaries and quick docs; sketching architecture or flow diagrams; sharing any artifact from a conversation as a link.

**Example prompts:**
- Publish these notes to pencil.md and give me the link.
- Turn this conversation into a pencil.md page with headings and a summary.
- Make a pencil.md drawing of this architecture with boxes and arrows.
- Update my pencil.md page about the launch plan with the new dates.
